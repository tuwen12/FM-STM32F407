## 二、UART2 ↔ IMU（DFRobot SEN0692，6 轴）

### 接线

| IMU 引脚 | 开发板排针 | 说明 |
|---|---|---|
| TX | **PA3**（USART2_RX） | 交叉连接 |
| RX | **PA2**（USART2_TX） | 交叉连接 |
| VCC | 3.3V | 模块若为 5V 供电按其手册 |
| GND | GND | 必须共地 |

### 协议与实现

- 物理串口：**115200-8-N-1**（`UART2_Init(115200)`，改速率改这一处）
- 上电自迁移：固件先以 9600 向模块写一次波特率寄存器（0x0003 = 0x00FF，表外值按 wiki 兜底规则落到 115200，掉电保存），等 300ms 后 MCU 切 115200；模块已迁移过时该命令无效、超时跳过，流程幂等
- 应用协议：**Modbus-RTU**，从机地址 0x4A（模块拨码开关默认），功能码 0x04 读输入寄存器
- 轮询机制：主循环状态机每 ~30ms 轮询——先读加速度（寄存器 0x0006），响应到达后接着读陀螺仪（0x0009），60ms 无响应判超时；响应帧 11 字节、大端 int16、CRC16 校验；**数据 ~33Hz，屏幕固定每 100ms 刷新一次（10Hz）**
- 数据换算：加速度 **±2g → 16384 LSB/g**；陀螺仪 **±250dps → 65.536 LSB/dps**
  ⚠️ 模块量程已被示例代码改写并掉电保存（出厂默认 ±8g/±2000dps，曾表现为静止 AZ≈4）。若把模块改回默认量程，需同步把 main.c 的 `IMU_ACC_LSB_PER_G` 改 4096、`IMU_GYR_LSB_PER_DPS` 改 16.384
- 屏幕显示：AX/AY/AZ（绿色，g）、GX/GY/GZ（青色，dps）、ROL/PIT（黄色，度，互补滤波姿态角）、IMU ONLINE/OFFLINE 状态行（黄/红）
- 姿态解算：互补滤波——加速度角 `roll=atan2(ay,az)`、`pitch=atan2(-ax,√(ay²+az²))` 与陀螺积分融合（0.98 陀螺 + 0.02 加速度，dt=30ms）；首次数据用加速度角初始化；符号约定按模块丝印 Z 朝上，若实测方向相反，把对应 gyro 项取负即可
- CRC16-Modbus 已实现，与 DFRobot wiki 示例帧逐一验证一致
- 发送接口：`UART2_SendData()` / `UART2_SendString()` 现成可用

## 三、电机控制 ↔ TSDA-C11A（脉冲位置模式）

### 接线（共阳极）

| 驱动器 CN3 | 连接到 | 说明 |
|---|---|---|
| PUL+ / DIR+ / ENA+ | +5V | 三路正端共用 5V |
| PUL− | **PD12**（TIM4_CH1） | 经 3.3V→5V 电平转换；低电平脉冲有效 |
| DIR− | **PB1** | 经电平转换；高电平正转，低电平反转 |
| ENA− | **PB5** | 经电平转换；高电平使能，低电平失能 |

### 实现要点

- 脉冲：TIM4_CH1 硬件 PWM，默认 **10kHz / 50%**，空闲时 PUL− 保持高电平（光耦关闭）
- 按键：**KEY_1（PA0）正转、KEY_2（PA1）反转**，两键都不按（或同时按下）停止，20ms 软件消抖
- 速度：电子齿轮 1:1、2500 线编码器（10000 脉冲/圈）时，10kHz ≈ 60RPM；改 `MOTOR_PULSE_HZ` 即可
- 驱动器需设为「位置模式—外部脉冲输入」，控制状态选「PLC 控制」
- 电平转换芯片需能承受每路光耦约 10~14mA 灌电流（建议 74HCT245/ULN2003 或光耦板），5V 地与开发板必须共地

## 四、时钟与串口速率

- 系统时钟 168 MHz（HSE 25M × PLL），APB1 = 42 MHz（USART2 挂 APB1），APB2 = 84 MHz
- UART1 = 115200-8-N-1（调试）；UART2 = 115200-8-N-1（IMU，上电自动从 9600 迁移）

## 五、注意事项

1. **PD13 陷阱**：8-2 表把 PD13 标为「闲置」，实际接触摸屏 CS，代码在用，别分配给外部器件
2. 板上引脚无隔离保护，电机类方案务必做隔离
3. 单引脚持续电流 ≤ 25mA，端口总电流 ≤ 100mA
4. W25Q128 只用前 10M 空间，后 6M 是中文字库，禁止全片擦除
5. 源码 UTF-8 编码（带 BOM）：Keil 需在 Edit → Configuration → Editor → Encoding 中选 UTF-8
